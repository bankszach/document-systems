Privacy policy

Effective: July 28, 2026

Service scope

Document Systems is a stateless document-modeling service published by Banks Inc. It accepts caller-supplied structured inputs and returns proposal-scoped compositions, validation receipts, profile information, rendered views, or portable release packets.

Data handling

The Document Systems application does not create user accounts, set advertising cookies, sell personal information, or intentionally persist MCP inputs, outputs, or portable packets. Results explicitly report NOT_PERSISTED.

Requests are processed by the service's hosting provider, Vercel, and may also be transmitted by the platform or MCP client through which a user invokes the service, including OpenAI products. Those providers may retain operational, security, or abuse-prevention logs under their own policies. Banks Inc. does not control a third-party client's independent retention practices.

What users should submit

Do not submit credentials, payment-card data, government identifiers, protected health information, private keys, or confidential records that you are not authorized to process. The service does not need those data types for its supported workflows.

Security and support

Report security issues through the repository's private security reporting channel. For other privacy questions, use the support page.

Changes

Material changes will be published on this page with a revised effective date. The public source repository records changes to the service code and policy pages.
