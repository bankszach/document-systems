Support

Document Systems is an experimental research prototype. It has not been submitted to the OpenAI Plugins Directory, and its marginal utility over ordinary document review remains unproven.

Product and installation help

Review the installation and usage guide or open a public support issue. Do not include private documents, credentials, or personal information in an issue.

Security reports

Use GitHub private vulnerability reporting for security concerns. Do not publish vulnerability details in a public issue.

Service status

The machine-readable health endpoint reports whether the deployment is responding. It does not prove the fitness or correctness of a particular document result.
