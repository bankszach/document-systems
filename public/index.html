Four bounded profiles

Normative, operational, research, and human-agent profiles give different document types a shared grammar without flattening their purpose.

Content-addressed results

Deterministic RFC 8785 canonicalization and SHA-256 digests make expression integrity testable.

Fail-closed action views

Human-action release is blocked when required roles, states, evidence gates, semantic assertions, or exception routes fail.

Portable release packets

One call returns a compact release gate or a FULL content-addressed packet that callers can store and verify.

Explicit limits

Validation never claims source truth, authority, behavioral success, human acceptance, operative status, or complete lineage.

The hosted MCP service is stateless and unauthenticated. It does not intentionally persist inputs, outputs, or portable packets. A healthy endpoint proves availability, not document correctness or product value.
